📖 About The Project

FitLog is a simple workout library website.  
It helps users find different exercises and learn how to do them.

Users can view exercise details, save workouts for later, and add workouts to their plan.

 🛠️ Technologies Used

- Next.js
- React
- JavaScript
- Tailwind CSS
- DaisyUI
- React Toastify
- Context API
- REST API

 ✨ Key Features

 1. 🏋️ Browse Exercises
Users can see different exercises on the home page and choose a workout they like.

 2. 📋 Exercise Details
Users can open an exercise and see its details, such as muscle group, equipment, sets, reps, and instructions.

 3. 📅 Add to Today's Plan
Users can add an exercise to their workout plan and keep track of what they want to do.

 4. 🔖 Save for Later
Users can save an exercise for later. This helps them easily find their favorite workouts again.

 5. 🔔 Toast Notifications
The website shows small messages when users save an exercise or add a workout to their plan.
